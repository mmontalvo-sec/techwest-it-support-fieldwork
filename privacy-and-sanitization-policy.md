# Privacy and Sanitization Policy

This repository is sanitized. Every case study documented here represents real work performed for real clients through Tech West PC Repair. To respect client privacy and uphold professional standards, all identifying information has been removed before publication.

---

## What Has Been Removed

The following categories of information are excluded from every document, screenshot, log, and asset in this repository:

| Category | Examples |
|----------|----------|
| Personal identifiers | Client names, family member names, business names |
| Contact information | Phone numbers, email addresses, physical addresses |
| Device identifiers | Serial numbers, asset tags, MAC addresses, host names |
| Network identifiers | Public IP addresses, Wi-Fi SSIDs, internal IP ranges that map to a real client |
| Credentials | Passwords, recovery keys, license keys, API tokens, account names |
| File contents | Personal photos, documents, browser tabs, application data |
| Sensitive categories | Medical, legal, or financial information |
| Business artifacts | Invoices with personal information, signed authorization forms, intake forms |
| System artifacts | Raw event logs, unredacted screenshots, registry exports |

---

## How Cases Are Documented

When a case study references real work, the documentation uses generic terms to describe the system or client:

- "client laptop"
- "client desktop"
- "small-office workstation"
- "Windows laptop"
- "affected endpoint"
- "client system"

Screenshots and photographs are either reconstructed in a clean test environment or redacted before inclusion. Any identifying information visible in a redacted image is fully obscured, not merely blurred.

---

## What Is Preserved

The following are preserved because they carry no privacy risk and demonstrate the value of the work:

- The reported symptoms and diagnostic process
- The tools and commands used
- The outcome of the work
- The technical lessons learned
- The recommendations provided to the client

---

## If Sanitization Is Ever Missed

If any reader, client, or future employer identifies content in this repository that appears to contain identifying or sensitive information, the maintainer welcomes notification and will remove or redact the content immediately.

Contact: through [techwestpcr.com](https://techwestpcr.com)

---

## Why This Matters

Sanitization is not just a privacy practice. It is a demonstration of professional judgment. An IT technician who handles client systems daily must understand what information is sensitive, how to protect it, and how to discuss work publicly without exposing the people the work was done for. This repository is designed to reflect that judgment.
