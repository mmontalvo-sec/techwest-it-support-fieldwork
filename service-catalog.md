# Service Catalog

Tech West PC Repair provides customer-facing IT support, hardware repair, and endpoint restoration services. The catalog below reflects the actual services performed and documented in this portfolio.

---

## Endpoint Support

| Service | Description |
|---------|-------------|
| Windows troubleshooting | Diagnosing and resolving issues on Windows 10 and Windows 11, including boot failures, slow performance, crashes, blue screen errors, and stability problems |
| Driver troubleshooting | Identifying missing, outdated, or conflicting drivers and applying clean installations |
| Account and login issues | Resolving Windows account, profile, and login problems where possible without data loss |
| System file repair | Using SFC, DISM, and related tools to restore corrupted Windows system files |
| Windows updates | Applying pending updates, resolving stuck or failed updates, validating post-update stability |

---

## Performance Optimization

| Service | Description |
|---------|-------------|
| Startup cleanup | Reviewing and disabling unnecessary startup applications |
| Temporary file removal | Cleaning system caches, browser caches, and Windows temp files |
| Disk health review | Running SMART checks and storage diagnostics with CrystalDiskInfo |
| Storage assessment | Evaluating whether an SSD upgrade would meaningfully improve performance |
| Application audit | Identifying installed software that is unused, redundant, or known to cause performance issues |

## Hardware Services

## Active Directory and User Account Support

| Service | Description |
|---------|-------------|
| Account lockout investigation | Identifying the source of account lockouts using Event Viewer security log (Event ID 4740) and resolving the root cause |
| Password resets | Secure password reset with forced change at first logon; temporary password communicated through a safe channel |
| New user provisioning | Creating domain accounts in ADUC with correct OU placement, group membership, and initial password policy |
| Account offboarding | Disabling accounts, stripping group memberships, moving to a disabled OU, and documenting the action |
| Group membership management | Troubleshooting file and resource access issues through security group review and membership changes |
| Active Directory administration | General ADUC navigation, OU structure, account property management |

## DNS, DHCP, and Network Connectivity

| Service | Description |
|---------|-------------|
| APIPA address diagnosis | Identifying and resolving DHCP lease failures that result in 169.254.x.x addresses |
| DHCP scope management | Reviewing active leases, clearing stale leases, expanding scope ranges, configuring exclusions |
| DNS resolution troubleshooting | Diagnosing name resolution failures using nslookup, confirming DNS server configuration, flushing the resolver cache |
| IP address conflict resolution | Identifying overlapping static and DHCP address assignments and applying scope exclusion best practices |
| General network connectivity | OSI-layer structured troubleshooting from physical layer through application layer |
| Windows network commands | Practical use of ipconfig, ping, nslookup, tracert, arp, and netstat for endpoint network diagnostics |
