## What This Portfolio Demonstrates

This repository documents approximately three years of hands-on, customer-facing IT support work performed through Tech West PC Repair. It is built to demonstrate technical, operational, and customer service skills directly relevant to:

- IT Support Technician
- Help Desk Technician
- Desktop Support Technician
- Field Service Technician
- Technical Support Specialist
- Junior Systems Administrator
- NOC Technician
- Cybersecurity-aware IT roles

Every case study follows a consistent format covering reported issue, diagnosis, tools used, work performed, outcome, client impact, and follow-up recommendations. All client identifying information has been removed.

## Customer Service Skills Demonstrated

Customer service is a core part of this work, not a side note. Three years of direct client interaction have produced consistent practices around:

- Explaining technical issues in plain language to non-technical users
- Setting realistic expectations when outcomes are uncertain
- Avoiding false promises, particularly around data recovery
- Providing written service summaries and follow-up recommendations
- Managing client emotions during high-stress incidents such as data loss or ransomware
- Educating clients on prevention so the same issue is less likely to recur

See [customer-service-approach.md](customer-service-approach.md) for detailed examples.

## Why This Matters for Recruiters

This portfolio shows the candidate has already performed core responsibilities found in IT support roles:

- Troubleshooting user-reported issues
- Supporting Windows endpoints across multiple versions
- Handling hardware upgrades and replacements
- Resolving printer, peripheral, and laser printer consumable issues
- Managing Active Directory user accounts: lockouts, password resets, provisioning, offboarding, group membership
- Troubleshooting DNS resolution failures, DHCP lease issues, and IP address conflicts

- Restoring systems after failure or compromise
- Documenting completed work in structured reports
- Communicating with non-technical users under pressure

The work is real. The documentation is real. The customer service experience is real. The only thing removed is client identifying information.
